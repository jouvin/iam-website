The IAM development team is pleased to announce the release of INDIGO IAM v1.12.1.

This release mainly provides bug fixes, as can be seen in the [release notes][release-notes].

The major highlights include:
* fix MFA with external providers (_experimental_)
* fix x509 personal certificate handling
* validate the read-only registration fields.

As usual, the IAM docker image can be obtained from [DockerHub][iam-login-service-docker].
